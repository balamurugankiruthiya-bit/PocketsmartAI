Phase 2: Requirement Analysis

1. Introduction

Requirement Analysis identifies the functional and technical requirements of the PocketSmart AI application. The system helps users manage their monthly income, expenses, and savings.

2. Functional Requirements

- The application should accept the user's name.
- The application should accept monthly income.
- The application should accept expenses for Food, Travel, Shopping, Education, and Other categories.
- The application should calculate total expenses.
- The application should calculate the remaining balance.
- The application should display savings recommendations.
- The application should display the results clearly.

3. Non-Functional Requirements

- The application should be simple and user-friendly.
- Calculations should be accurate.
- The application should respond quickly.
- The application should validate numerical inputs.
- The application should be easy to maintain.

4. Hardware Requirements

- Computer or laptop
- Minimum 4 GB RAM recommended
- Keyboard and mouse
- Internet connection for installation and online access

5. Software Requirements

- Operating System: Windows
- Programming Language: Python
- Framework: Streamlit
- Code Editor: Visual Studio Code
- Version Control: Git and GitHub
- Web Browser: Google Chrome or Microsoft Edge

6. Input Requirements

- User name
- Monthly income
- Food expenses
- Travel expenses
- Shopping expenses
- Education expenses
- Other expenses

7. Output Requirements

- Total monthly expenses
- Remaining balance
- Savings amount or recommendation
- Budget summary

8. Feasibility Study

Technical Feasibility

Python and Streamlit provide the tools required to develop the application.

Economic Feasibility

The project uses free development tools and open-source technologies.

Operational Feasibility

The application is easy to use and helps users understand their monthly budget.

9. Conclusion

The requirement analysis defines the necessary inputs, outputs, software, hardware, and functions required to develop PocketSmart AI.
