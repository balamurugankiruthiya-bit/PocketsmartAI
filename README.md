PocketSmart AI

Project Overview

PocketSmart AI is a smart budget management application developed using Python and Streamlit.

Features

- Enter monthly income
- Enter expenses
- Calculate total expenses
- Display remaining balance
- Provide savings recommendations

Technologies Used

- Python
- Streamlit
- Visual Studio Code

Project Phases

1. Brainstorming and Ideation
2. Requirement Analysis
3. Project Design
4. Project Planning
5. Project Development
6. Project Testing
7. Project Documentation
8. Project Demonstration

Conclusion

PocketSmart AI helps users manage their monthly budget and understand their spending.
