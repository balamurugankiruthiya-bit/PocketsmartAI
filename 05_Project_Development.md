Phase 5: Project Development

1. Introduction

The Project Development phase involves implementing the PocketSmart AI application using Python and Streamlit. The application helps users calculate their monthly expenses, remaining balance, and savings recommendations.

2. Technologies Used

- Programming Language: Python
- Framework: Streamlit
- Code Editor: Visual Studio Code
- Version Control: Git and GitHub

3. Modules Developed

User Input Module

Accepts the user's name and monthly income.

Expense Input Module

Accepts expenses in five categories: Food, Travel, Shopping, Education, and Other.

Budget Calculation Module

Calculates total expenses by adding all expense categories.

Total Expenses = Food + Travel + Shopping + Education + Other

Remaining Balance = Monthly Income - Total Expenses

Recommendation Module

Displays a basic financial recommendation based on the remaining balance.

Output Module

Displays the total expenses, remaining balance, and recommendation on the screen.

4. Development Process

1. Created the Python application file named app.py.
2. Imported the Streamlit library.
3. Designed the application title and subtitle.
4. Added input fields for name, income, and expenses.
5. Implemented the budget calculation logic.
6. Added the Calculate Budget button.
7. Displayed the budget summary and savings recommendation.
8. Saved and prepared the application for testing.

5. Application Features

- Simple and user-friendly interface.
- Monthly income entry.
- Expense tracking in five categories.
- Automatic total expense calculation.
- Remaining balance calculation.
- Basic savings recommendations.

6. Running the Application

1. Open the project folder in Visual Studio Code.
2. Open the terminal.
3. Install Streamlit if it is not already installed using: pip install streamlit
4. Run the application using: streamlit run app.py
5. Open the local URL displayed in the terminal.

7. Conclusion

The PocketSmart AI application was developed using Python and Streamlit. It accepts income and expense details, calculates the budget, and displays a summary with basic financial recommendations.
