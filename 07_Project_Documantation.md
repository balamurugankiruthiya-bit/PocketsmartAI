Phase 7: Project Documentation

1. Project Overview

PocketSmart AI is a budget management application designed to help users understand their monthly income, expenses, and remaining balance. It provides a simple way to organize expenses and view basic savings recommendations.

2. Project Objectives

- Track monthly income and expenses.
- Calculate total expenses.
- Calculate the remaining balance.
- Display a budget summary.
- Provide basic savings recommendations.

3. Technologies Used

- Programming Language: Python
- Framework: Streamlit
- Code Editor: Visual Studio Code
- Version Control: Git and GitHub

4. System Requirements

Hardware

- Computer or laptop
- Keyboard and mouse
- 4 GB RAM recommended

Software

- Windows or another compatible operating system
- Python
- Streamlit
- Visual Studio Code
- Web browser

5. Installation Instructions

1. Install Python on the computer.

2. Open the PocketSmartAI project folder in Visual Studio Code.

3. Open the integrated terminal.

4. Install Streamlit by running:
   
   pip install streamlit

5. Ensure the main application file is named app.py.

6. How to Run the Application

1. Open the project folder in Visual Studio Code.

2. Open Terminal → New Terminal.

3. Run the following command:
   
   streamlit run app.py

4. Open the local URL shown in the terminal.

5. Enter the name, monthly income, and expenses.

6. Click the budget calculation button, if available.

7. View the total expenses, remaining balance, and recommendation.

7. Main Features

- User name input
- Monthly income entry
- Five expense categories: Food, Travel, Shopping, Education, and Other
- Total expense calculation
- Remaining balance calculation
- Budget summary and savings recommendation

8. Limitations

- Results depend on the values entered by the user.
- The basic application does not automatically connect to bank accounts.
- Advanced financial planning features may not be available.

9. Future Enhancements

- Monthly expense charts
- Expense history
- Data storage
- Budget alerts
- Downloadable reports
- Improved savings recommendations

10. Conclusion

PocketSmart AI demonstrates how Python and Streamlit can be used to build a simple budget management application. The project helps users understand their expenses and remaining balance and supports better budgeting decisions.
